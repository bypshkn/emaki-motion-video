Editorial (light): a magazine spread that moves; warm paper, serif headlines, one vermilion accent, calm masked line reveals, felt piano.

Use when: thought leadership, case studies, reports, "story" explainers, client presentations that should feel premium and quiet.
Signature moves: `Text.reveal(t, "mask", by="line")`; kicker in spaced caps above the headline; hairline `Line.draw_on`; `Text.highlight(words, t)` in accent; oversized serif numbers (`style="number"`); `Wipe`/`Slide` transitions; asymmetric 12-column layouts.
Avoid: glitch, neon, overshoot easing, particles, centered-everything layouts.
Fonts: Lora + Lato (free, often preinstalled on Linux). Better: Playfair Display or Cormorant Garamond for display, Inter for body (free, Cyrillic).
