Terminal: a machine speaking in first person; dark screen, typed copy with a scramble edge, HUD corners, glitch at every line edge, CRT texture, drone + key clicks.

Use when: AI/product voice, developer tools, "behind the scenes" of a system, manifesto lines.
Signature moves: `Text.typewriter(cps=22, scramble=3, cursor=True)`; `P.fx_track("glitch")` pulses at line in/out; HUD as `DynamicText` timecodes; progress hairline; `sound.genre: terminal`.
Avoid: colour accents, bouncy easing, particles, glossy gradients.
Reference implementation: tests/regression_terminal/video.py (the 14 s demo ported to the engine).
